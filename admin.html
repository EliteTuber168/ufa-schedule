Sign in

Saving needs a GitHub token that can write to the ufa-schedule repo. You can still build matchups and copy Discord posts without signing in.
  1. Open your GitHub tokens and edit your token (or make a new one).
  2. Repository access → Only select repositories → add ufa-schedule.
  3. Permissions → Repositories → Contents: Read and write. Save.

Matchups

Auto-schedule

Fills the rest of the week with active teams that don't have a game yet. It avoids rematches (especially last week's), and if there's an odd number it gives the bye to whoever has had the fewest. Suggested games show in blue until you save.

Discord post

Team names only ping in Discord if you add role IDs in Teams & roles. Otherwise they post as plain text like "@Minnesota Vikings".

Teams

Status Auto follows the rules in Settings; Always/Never overrides them. Only active teams get scheduled. Discord role ID: turn on Developer Mode in Discord, right-click the team role, then Copy Role ID. With an ID, the post pings the role for real.
